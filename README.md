# Smart Parking Finder

A responsive web app to find parking locations, check availability and compare charges.
Built with plain HTML, CSS and JavaScript. No frameworks, no APIs, no paid services.

## Files

- `index.html` - page structure
- `style.css` - styling and responsive layout
- `script.js` - sample data and all interactive features

## Run in VS Code

1. Put the three files (`index.html`, `style.css`, `script.js`) in one folder, e.g. `smart-parking-finder`.
2. In VS Code choose **File > Open Folder** and open that folder.
3. Install the **Live Server** extension (by Ritwick Dey) from the Extensions panel (Ctrl+Shift+X).
4. Right-click `index.html` and choose **Open with Live Server**. The app opens at `http://127.0.0.1:5500`.

Without the extension you can also double-click `index.html` to open it in any browser.

## Features

- Home page with title, introduction and live overview stats
- 10 sample parking locations with available / occupied / total spaces
- Hourly and daily charges
- Search by name or area (updates as you type)
- Filter: All, Available, Almost full, Full
- Sort by name, availability or price
- Select a location, or open a details dialog with facilities, timings and a cost estimator
- Reserve or cancel a space (availability updates instantly)
- "Refresh availability" simulates live changes
- Responsive for desktop and mobile
